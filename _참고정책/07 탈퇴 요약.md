# ADLY 회원탈퇴 처리 요약표

## 1. 탈퇴 기본 정보

| 항목 | 내용 |
| --- | --- |
| 탈퇴 방식 | 사용자 자발적 신청만 허용 (어드민 강제 탈퇴 없음) |
| 탈퇴 경로 | 내 정보 > 회원탈퇴 |
| 탈퇴 가능 상태 | 승인대기, 승인, 반려 |
| 탈퇴 불가 | 정지 (로그인 차단), Sales Manager 담당 사용자 있는 경우 (이관 후 가능) |
| 재가입 | 동일 Google 계정 즉시 가능, 신규 회원 처리, 기존 데이터·권한 복구 불가 |

## 2. 탈퇴 시 즉시 처리

| 처리 항목 | 대상 사용자 | 처리 방식 |
| --- | --- | --- |
| 사용자 상태 | 전체 | 탈퇴(WITHDRAWN) 변경 |
| 로그인 세션 | 전체 | 즉시 만료 + 강제 로그아웃 |
| Admin Role | 전체 | 전체 회수 |
| 솔루션 권한·Solution Role | 전체 | 전체 회수 |
| 광고주·자산 접근 권한 | 전체 | 종료 |
| 자산요청 (요청중) | 전체 | 일괄 반려 (사유: 사용자 탈퇴로 인한 자동 반려) |
| 자산요청 (완료/반려) | 전체 | 상태·이력 유지 |
| 이용설정 변경 요청 (요청중) | 광고주/대행사 | 일괄 "요청취소" 처리 |
| 업무 데이터 | 전체 | 각 솔루션 정책에 위임 (익명화 후 보유·활용 가능) |
